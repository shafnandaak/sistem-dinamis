# Arsip: Fitur Provinsi Lain (Pengembangan Lanjutan)

Kode di folder ini adalah implementasi awal agar model dapat dijalankan untuk provinsi selain Jawa Barat.
Fitur ini dinonaktifkan dari aplikasi karena seluruh data awal dan data historis perlu disesuaikan per provinsi.
Folder ini dikecualikan dari `tsconfig.json` sehingga tidak ikut di-build.

- `baseline-provinsi-lain-page.tsx` — halaman `/baseline/provinsi-lain` versi lama.
- `ProvincePrepCard.tsx` — komponen pemilihan provinsi + initial value.
